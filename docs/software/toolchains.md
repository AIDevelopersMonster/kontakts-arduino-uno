# Матрица toolchain

| Среда | Для чего | Обязательный результат |
|---|---|---|
| Arduino IDE 2 | обучение и быстрый ручной запуск | инструкция выбора платы и порта |
| Arduino CLI | автоматизация и точная фиксация зависимостей | команда компиляции и FQBN |
| PlatformIO | сложные проекты, среды, тесты | `platformio.ini` и фиксированная платформа |
| avr-gcc | низкоуровневые эксперименты | Makefile/CMake и карта памяти |
| HIL-стенд | проверка реального ввода-вывода | протокол и машинно-читаемый отчёт |

Для UNO R3 базовый FQBN Arduino CLI: `arduino:avr:uno`.
Для PlatformIO базовый board ID: `uno`.
