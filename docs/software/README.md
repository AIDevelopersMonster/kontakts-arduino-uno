# Среды программирования

## Поддерживаемые линии

1. **Arduino IDE 2** — основной стартовый путь.
2. **Arduino CLI** — воспроизводимая сборка, скрипты и CI.
3. **PlatformIO Core/IDE** — многоплатформенные проекты, зависимости, тестирование и анализ.
4. **avr-gcc / avr-libc** — понимание низкого уровня и контроль сборки.
5. **Прямое программирование регистров** — отдельная инженерная линия, не смешиваемая с вводными уроками.
6. **Симуляторы** — предварительная проверка логики; реальные электрические выводы делаются только по стенду.

Каждый проект указывает точные версии core, библиотек и среды либо содержит lock/profile-механизм.
