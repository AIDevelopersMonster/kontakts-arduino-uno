# Чек-лист индексируемой статьи и форума KONTAKTS

Это редакционная и техническая цель, а не обещание позиции в поиске.

## Страница статьи

- один точный `<title>` и один видимый `<h1>`;
- уникальное краткое описание страницы;
- постоянный канонический URL;
- автор, дата публикации и дата обновления;
- содержательное введение до длинных списков и кода;
- изображения с осмысленными `alt`;
- внутренние ссылки на серию, плату, модуль и проект;
- JSON-LD `Article`/`TechArticle`, если шаблон сайта позволяет;
- ссылка на GitHub-релиз, а не только на ветку `main`;
- ссылка на отдельную форумную тему обсуждения.

## Форумная тема

- заголовок описывает конкретный вопрос;
- первое сообщение содержит краткий ответ, схему и постоянные ссылки;
- важные исправления переносятся в первое сообщение;
- сообщения не закрываются для чтения поисковым роботам;
- дублирующие URL сводятся к каноническому адресу;
- пагинация не должна создавать ложные копии первой страницы.

## Технический минимум сайта

- HTTPS и единый вариант домена;
- корректные коды ответа без циклических редиректов;
- sitemap с каноническими URL;
- robots.txt не блокирует статьи, изображения и необходимые ресурсы;
- мобильная читаемость;
- структурированные данные проверяются Rich Results Test;
- после крупных изменений используется URL Inspection в Search Console.
