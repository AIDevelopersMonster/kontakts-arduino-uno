# Модель контента

## Типы материалов

| Код | Тип | Результат |
|---|---|---|
| `BOARD` | плата | идентификация, электрические особенности, совместимость |
| `SHIELD` | шилд/плата расширения | pin map, конфликты, питание, тесты |
| `MODULE` | модуль | схема подключения, библиотека, ограничения |
| `SENSOR` | датчик | метрологические характеристики и калибровка |
| `SOFT` | программная среда | установка, сборка, отладка, воспроизводимость |
| `CODE` | программный паттерн | минимальный пример, тесты, анализ памяти/времени |
| `PROJ` | законченный проект | BOM, механика, электроника, firmware, испытания |
| `EXP` | эксперимент | гипотеза, протокол, данные, анализ |
| `PAPER` | статья/препринт | научно-технический текст и архивируемые материалы |

## Уровни аудитории

- `START` — первый опыт;
- `MAKER` — самостоятельная сборка;
- `ENGINEERING` — расчёты, ограничения и тесты;
- `R&D` — измерения, статистика и воспроизводимость.

## Доказательность

Каждое существенное утверждение маркируется источником:

- `MEASURED` — измерено в проекте;
- `DATASHEET` — следует из документации компонента;
- `VENDOR` — заявлено продавцом или производителем, но не проверено;
- `COMMUNITY` — найдено в стороннем опыте;
- `INFERENCE` — инженерный вывод;
- `UNKNOWN` — требует проверки.
