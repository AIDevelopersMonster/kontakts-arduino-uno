# Аппаратная база

## Семейство UNO

- UNO R3 DIP;
- UNO R3 SMD;
- UNO WiFi Rev2;
- UNO R4 Minima;
- UNO R4 WiFi;
- китайские совместимые и модифицированные платы;
- платы только в UNO-форм-факторе, но с другим MCU.

## Карточка платы должна содержать

- фотографии обеих сторон;
- маркировку MCU и USB-моста;
- частоту и источник тактирования;
- схему питания и тип стабилизатора;
- разъёмы и распиновку;
- bootloader и способ восстановления;
- совместимость шилдов;
- измеренное потребление;
- проверенные среды сборки;
- известные аппаратные отличия.
