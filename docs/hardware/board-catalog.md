# Начальная классификация UNO-плат

| Группа | Основной MCU | Назначение в проекте |
|---|---|---|
| UNO R3 DIP | ATmega328P, 16 МГц | эталонная ремонтопригодная 8-битная плата |
| UNO R3 SMD | ATmega328P, 16 МГц | эталон SMD-исполнения |
| UNO-совместимые AVR | обычно ATmega328P/328PB | сравнение китайских реализаций и компонентов |
| UNO WiFi Rev2 | ATmega4809 | отдельная 8-битная ветвь с сетевым модулем |
| UNO R4 Minima | Renesas RA4M1, 48 МГц | 32-битное продолжение форм-фактора |
| UNO R4 WiFi | RA4M1 + ESP32-S3 | 32-битная сетевая и интерфейсная ветвь |
| UNO-form-factor | STM32, ESP32, RP2040, STM8 и др. | совместимость механики и шилдов проверяется отдельно |

Форма платы не гарантирует совместимость по напряжению, pin mapping, библиотекам, таймерам и поведению периферии.
