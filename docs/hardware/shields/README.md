# Шилды Arduino UNO

Раздел содержит инженерные карточки плат расширения, фотографии конкретных экземпляров, предварительную идентификацию, схемы безопасного включения и воспроизводимые стендовые проверки.

| Шилд | Статус | Материал |
|---|---|---|
| Sensor Shield V5.0 | `DRAFT / HARDWARE-IDENTIFIED` | [`sensor-shield-v5`](sensor-shield-v5/) |
| Multi-Function Shield / HW-262-compatible | `DRAFT / PINOUT-UNVERIFIED` | [`multi-function-shield-hw262`](multi-function-shield-hw262/) |

Одинаковое торговое название или внешний вид не считаются доказательством одинаковой электрической схемы. Каждая аппаратная ревизия должна подтверждаться фотографиями, шелкографией, прозвонкой и тестовыми скетчами.
