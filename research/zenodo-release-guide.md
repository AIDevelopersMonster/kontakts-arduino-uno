# Релиз GitHub → Zenodo

## Когда архивировать

- получен устойчивый результат, который должен цитироваться;
- опубликован набор данных;
- завершена версия методики или software artifact;
- статья ссылается на конкретную версию кода;
- важен неизменяемый архив отрицательного результата.

## Порядок

1. Очистить репозиторий от секретов и временных файлов.
2. Проверить `CITATION.cff`.
3. Зафиксировать версии зависимостей.
4. Добавить данные, описание формата и контрольные суммы.
5. Создать GitHub Release с семантической версией.
6. После подключения репозитория к Zenodo дождаться архивации релиза.
7. Добавить DOI релиза и concept DOI в статью, каталог контента и README проекта.

Не следует одновременно добавлять `.zenodo.json` и рассчитывать, что Zenodo возьмёт метаданные из `CITATION.cff`: при наличии обоих файлов приоритет имеет `.zenodo.json`.
