# Исследовательская линия

Arduino UNO рассматривается не только как учебная плата, но и как доступный объект для воспроизводимых экспериментов по embedded systems.

## Перспективные направления

- временная точность, латентность и джиттер;
- свойства ADC/PWM и влияние питания;
- поведение при сбоях и brown-out;
- аппаратно-достоверные диапазоны входов;
- переносимость firmware между реализациями UNO;
- качество библиотек и скрытые конфликты ресурсов;
- долговременная устойчивость EEPROM и flash;
- методики обучения электронике с измеримыми результатами;
- тестовые корпуса для статического и формального анализа.
