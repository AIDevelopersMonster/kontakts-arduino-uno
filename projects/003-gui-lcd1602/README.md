# KONTAKTS-UNO-PROJ-003 — GUI LCD1602 I2C

**Статус: `BENCH-TESTED`** — прошивка, Windows GUI, вывод текста, подсветка и пользовательские символы проверены пользователем на реальной Arduino UNO с LCD1602 I2C.

## Видео

[YouTube Shorts — демонстрация GUI LCD1602 I2C](https://youtube.com/shorts/x6kkZxzQmYg)

## Что делает проект

Windows-приложение управляет символьным LCD1602 через Arduino UNO и USB/Serial:

- два поля ровно по **16 символов**;
- отправка полного экрана 16×2;
- управление подсветкой и очистка дисплея;
- выбор COM-порта и журнал обмена;
- редактор пользовательского символа **5×8 пикселей**;
- восемь аппаратных слотов пользовательских знаков;
- встроенная библиотека значков;
- сохранение собственных значков в `gui/user_symbols.json`;
- вставка пользовательских знаков в строки кнопками ①…⑧.

## Аппаратная схема

Для обычного LCD1602 с I2C-переходником PCF8574:

| LCD1602 I2C | Arduino UNO |
|---|---|
| GND | GND |
| VCC | 5V |
| SDA | A4 / SDA |
| SCL | A5 / SCL |

По умолчанию прошивка использует адрес `0x27`. Если модуль имеет адрес `0x3F` или другой, измените `LCD_ADDRESS` в скетче.

## Требования

- Arduino UNO R3 или совместимая плата;
- LCD1602 с I2C-переходником;
- Arduino IDE 2.x;
- библиотека [`LiquidCrystal_I2C` 2.0.0](https://github.com/markub3327/LiquidCrystal_I2C);
- Windows 10/11;
- Python 3.10 или новее;
- USB-кабель с передачей данных.

## 1. Загрузка прошивки

Откройте в Arduino IDE:

```text
firmware/arduino-ide/gui_lcd1602/gui_lcd1602.ino
```

Установите библиотеку [`markub3327/LiquidCrystal_I2C`](https://github.com/markub3327/LiquidCrystal_I2C) версии **2.0.0**, выберите **Arduino UNO**, нужный COM-порт и загрузите скетч. Библиотека распространяется по лицензии MIT.

После запуска LCD должен показать:

```text
KONTAKTS LCD1602
USB GUI READY
```

## 2. Запуск GUI

Дважды щёлкните:

```text
run_gui.bat
```

Скрипт создаст `.venv`, установит `pyserial` и запустит приложение.

Ручной запуск:

```powershell
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r gui\requirements.txt
.venv\Scripts\python -m gui.app
```

## 3. Работа с экраном

1. Закройте Serial Monitor Arduino IDE.
2. Запустите GUI и подключитесь к COM-порту.
3. Введите до 16 знаков в каждую строку.
4. Нажмите **Отправить экран**.
5. Кнопки ①…⑧ вставляют пользовательские символы из соответствующих слотов.

Текущая версия передаёт обычные печатные ASCII-символы. Неподдерживаемые Unicode-знаки, включая большинство русских букв, заменяются знаком `?`. Русские буквы можно постепенно добавлять как собственные 5×8-глифы, но одновременно LCD хранит только восемь таких знаков.

## 4. Генератор и библиотека символов

Во вкладке **Генератор символов 5×8**:

1. выберите слот 1–8;
2. включайте и выключайте пиксели кликом;
3. задайте название;
4. нажмите **Применить к слоту**;
5. нажмите **Отправить этот слот** либо **Отправить все 8 слотов**.

Встроенная библиотека содержит более двадцати значков: сердце, улыбку, стрелки, галочку, крест, термометр, батарею, колокольчик, каплю, часы, управление воспроизведением и другие.

## Протокол Serial

Скорость: **115200 бод**, строки завершаются `\n`.

| Команда ПК | Ответ платы | Назначение |
|---|---|---|
| `PING` | `PONG GUI_LCD1602/1` | проверка совместимости |
| `STATUS` | `STATE ADDR=0x27 BACKLIGHT=1` | состояние LCD |
| `CLEAR` | `OK CLEAR` | очистка дисплея |
| `BACKLIGHT ON` | `OK BACKLIGHT ON` | включение подсветки |
| `BACKLIGHT OFF` | `OK BACKLIGHT OFF` | выключение подсветки |
| `TEXT <32HEX> <32HEX>` | `OK TEXT` | две строки по 16 байт |
| `GLYPH 0 <16HEX>` | `OK GLYPH 0` | восемь строк 5-битного глифа |

Текст передаётся шестнадцатерично, поэтому байты пользовательских слотов `0..7`, пробелы и знаки пунктуации не конфликтуют с разделителями протокола.

## Автоматические тесты


Либо запустите `run_tests.bat`.

Проверяются ограничение в 16 знаков, упаковка двух строк, слоты 0–7, генерация команд глифов, разбор состояния устройства и сохранение пользовательской библиотеки. Текущий результат: **13 из 13 тестов успешно**.
