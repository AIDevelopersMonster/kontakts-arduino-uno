# Проекты

Формат имени: `NNN-short-slug`.

Каждый законченный проект содержит:

- `README.md` — цель, схема, BOM, сборка, проверка и ограничения;
- `firmware/` — исходный код и среды сборки;
- `hardware/` — схемы, PCB/CAD или таблицы соединений;
- `test/` — тестовые процедуры и результаты;
- `media/` — только собственные или лицензированные иллюстрации;
- `publication/` — черновики статьи и сценария видео;
- `data/` — при наличии измерений.
