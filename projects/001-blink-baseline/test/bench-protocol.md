# Стендовый протокол

1. Зафиксировать производителя, маркировку MCU и USB-UART.
2. Подключить плату только по USB без внешней нагрузки.
3. Собрать проект с включёнными предупреждениями.
4. Загрузить firmware.
5. Открыть Serial 115200.
6. Записать не менее 20 строк `transition=`.
7. Проверить, что интервалы по `millis()` равны 500 мс с точностью дискретности системного таймера.
8. Сохранить лог в `test/results/<board>-<date>.txt`.
9. Отдельно отметить сбои загрузки, reset и потерю порта.
