# KONTAKTS Arduino UNO

**Новая русскоязычная инженерная база знаний об Arduino UNO: от первых опытов до воспроизводимого R&D.**

[Форум Arduino UNO на KONTAKTS](http://kontakts.ru/forumdisplay.php/191) · GitHub-код и документация · YouTube-демонстрации · архивируемые релизы Zenodo

## Зачем этот проект

Arduino UNO R3 действительно относится к старому поколению микроконтроллерных плат, но остаётся удобной эталонной 8-битной лабораторией: простая архитектура, огромная база модулей, понятный форм-фактор, дешёвые совместимые платы и возможность исследовать систему от электрического сигнала до машинного кода.

Задача проекта — не повторять старые уроки, а заново выстроить проверяемую экосистему:

- рассказывать об оригинальных и совместимых UNO-платах, особенно китайских исполнениях;
- проверять реальные отличия: микроконтроллер, USB-UART, стабилизатор, кварц/резонатор, загрузчик, питание и качество монтажа;
- создавать и сопровождать код в Arduino IDE, Arduino CLI, PlatformIO и других средах;
- документировать шилды, модули, датчики и интерфейсы;
- доводить прототипы до законченных устройств;
- публиковать измерения, отрицательные результаты и исследовательские пакеты;
- связывать GitHub, статьи KONTAKTS, форумные обсуждения, YouTube и Zenodo единым идентификатором материала.

## Роли площадок

| Площадка | Каноническая роль |
|---|---|
| **GitHub** | исходный код, схемы, данные, версии, проверки, задачи и релизы |
| **KONTAKTS** | индексируемые русские статьи, долговременные страницы проектов и форумные обсуждения |
| **YouTube** | демонстрации, испытания, сравнения плат и пошаговые сборки |
| **Zenodo** | неизменяемые версии ПО, наборов данных, методик и научно-технических статей с DOI |

## Основные разделы

- [`docs/hardware/`](docs/hardware/) — платы UNO, совместимые исполнения, шилды, модули и датчики.
- [`docs/software/`](docs/software/) — IDE, CLI, toolchain, библиотеки, тестирование и автоматическая сборка.
- [`projects/`](projects/) — законченные проекты с BOM, схемой, кодом, испытаниями и материалами публикации.
- [`research/`](research/) — воспроизводимые эксперименты, данные и будущие Zenodo-пакеты.
- [`content/`](content/) — единый каталог материалов и связи между площадками.
- [`docs/legacy/`](docs/legacy/) — карта прежнего раздела форума №191 без автоматического признания старых материалов актуальными.

## Воспроизводимые примеры

[`projects/001-blink-baseline`](projects/001-blink-baseline/) — не просто Blink, а базовая проверка платы, загрузки, последовательного порта и неблокирующего таймера. Один и тот же проект представлен для Arduino IDE/CLI и PlatformIO.

[`projects/002-gui-blink`](projects/002-gui-blink/) — Windows GUI для управления встроенным светодиодом Arduino UNO через USB/Serial: включение, выключение, регулируемое мигание, журнал обмена и проверяемый текстовый протокол. Статус: `BENCH-TESTED`.

## Статусы материалов

Каждая статья и разработка должна явно указывать статус:

- `DRAFT` — черновик;
- `BENCH-TESTED` — проверено на стенде, но ещё не воспроизведено независимо;
- `REPRODUCED` — результат повторён на другой плате или другим участником;
- `RELEASED` — зафиксированный релиз;
- `ARCHIVED` — релиз сохранён в Zenodo;
- `LEGACY-UNREVIEWED` — старый материал, ещё не прошедший повторную проверку.

## Как начать

1. Прочитать [`docs/strategy/ecosystem.md`](docs/strategy/ecosystem.md).
2. Выбрать тему в [`BACKLOG.md`](BACKLOG.md).
3. Создать карточку материала по шаблону [`docs/editorial/article-template.md`](docs/editorial/article-template.md).
4. Добавить или обновить запись в [`content/catalog.json`](content/catalog.json).
5. Проверить репозиторий командой `python tools/validate_repo.py`.
6. Открыть issue или pull request.

## Лицензирование

Решение о лицензиях ещё должно быть утверждено владельцем проекта. До этого момента материалы нельзя считать автоматически переданными под свободной лицензией. Рекомендованная модель описана в [`LICENSES/README.md`](LICENSES/README.md).
